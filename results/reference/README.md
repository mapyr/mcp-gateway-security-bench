# results/reference

Reference results for the two **controls** — not a real intermediary, the bench's
own yardstick. They are regenerated by:

```sh
mcpsb run --target vulnerable --out results/reference --format both
mcpsb run --target secure     --out results/reference --format both
```

* `vulnerable.*` — every implemented sub-ID is `FAIL` (nothing is protected).
* `secure.*` — every implemented sub-ID is `PASS` (everything is protected).

This is the executable definition of what the bench considers correct
(GOVERNANCE §3): if you doubt a test, read what it does to these two.

Third-party target results are **not** published here — they follow the
embargo in `DISCLOSURE.md`. These controls are the bench's own, so they carry no
embargo.
